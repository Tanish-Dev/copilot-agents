How to Set Up

VS Code Setup

1

Open Copilot Chat → click the agents dropdown → Configure Custom Agents…

2

Choose Workspace (repo-specific) or User Profile (global across all projects)

3

Name the file → VS Code creates .github/agents/your-agent.agent.md

4

Paste the agent config below → save → agent appears in dropdown instantly

CLI & GitHub.com Setup

1

Commit the .agent.md files into .github/agents/ in your repo's default branch

2

CLI: run copilot --agent=agent-name --prompt "your task" from terminal

3

GitHub.com: go to github.com/copilot/agents → pick repo → select agent → assign task

4

Copilot opens a PR automatically when done. Track progress in the Agents panel.

Efficiency Tips

⚡ Context Loading

  • Use @workspace before complex tasks so the agent sees your full repo structure
  • Name the file explicitly: "review src/api/chatbot.py" not "review my chatbot"
  • Chain agents: Run System Designer first → then Full Stack Dev to implement it

🎯 Trigger Words

  • Add trigger words in the description (like "secaudit", "gsoc", "review") — Copilot auto-routes
  • CLI flag: --agent=ai-engineer forces a specific agent without typing
  • Handoffs: Use VS Code's handoff feature to chain agents in one session

🧠 Model Selection

  • Use claude-sonnet for code-heavy tasks (AI Engineer, Full Stack Dev)
  • Use GPT-4.1 (included free) for fast, routine tasks like docstrings
  • Use Claude Opus for GSoC proposals and system design — bigger context

📦 Global vs Workspace

  • User profile agents (global): Code Reviewer, Doc Writer, Security Auditor
  • Workspace agents (repo-specific): AI Engineer, GSoC Contributor, Full Stack Dev
  • Global ones are available across every project you open in VS Code

🔄 Workflow Combos

  • New feature: System Designer → Full Stack Dev → Code Reviewer
  • AI project: AI Engineer → ML Researcher → Security Auditor → Doc Writer
  • GSoC: GSoC Contributor (explore) → Doc Writer (proposal) → Code Reviewer (PR)

🛠 MCP Supercharger

  • Connect GitHub MCP to let agents read issues, PRs, and repo data natively
  • Add Figma MCP to Full Stack Dev for design-to-code directly
  • Add your local docs MCP so agents know your team conventions
